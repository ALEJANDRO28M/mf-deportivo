# MF Deportivo · Avances

Página web de **MF Deportivo — Entrenamientos personalizados de fútbol** (entrenador: Marlon Andrés Forero).

Permite llevar el plantel, evaluar a cada jugador con la ficha de 54 aspectos en escala 1–5, registrar el seguimiento de sesiones y enviar a las familias el informe en PDF por correo o WhatsApp.

**Página:** https://alejandro28m.github.io/mf-deportivo/

- Un solo archivo (`index.html`), sin servidor ni base de datos externa.
- Los datos se guardan en el navegador del dispositivo; en **Ajustes → Copia de seguridad** se exportan/importan para pasarlos a otro equipo.
- Envío de correos con PDF adjunto mediante [EmailJS](https://www.emailjs.com) (configuración en Ajustes → Correo).
- PDF generado en el navegador con [jsPDF](https://github.com/parallax/jsPDF).
